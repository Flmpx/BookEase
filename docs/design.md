# 设计文档

## 基础设施
具体代码参见 [base.hpp](../base/base.hpp) 和 [base.cpp](../base/base.cpp)  

### 基础类型
| 关键字 | 名称 | 真实类型 | 介绍 |
| --- | --- | --- | --- |
| `int_t` | 有符号整数 | `int64_t` | 作为该项目的有符号整数类型, 所有的结构体或者类中若使用整数, 使用的都是它 |
| `uint_t` | 无符号整数 | `int64_t` | 作为该项目的无符号整数, 当有些类型参与位运算或者不存在负数的时候使用的就是它 |
| `float_t` | 浮点数 | `double` | 价格使用的就是这个类型 |
| `BookCategory` | 书籍类别 | 枚举 | 有五种: `textbook`, `fiction`, `academic`, `exam` 和 `other`, 还有一个是 `all`, 这个是方便某些函数的默认参数选择全部类别的书籍 |
| `BookStatus` | 书籍状态 | 枚举 | 有四种: `on_sale`, `reserved`, `sold` 和 `removed`, 还有一个是 `all`, 这个是方便某些函数的默认参数选择全部状态的书籍 |
| `Range` | 整数范围 | 模板类 | 设定范围之后, 该类提供判断传入的数据是否符合当前设定范围以及强制将数据改成合理范围的方法, 其中, 该模板类已对 `float_t` 类型进行了具体化 |
| `Time` | 时间 | 类 | 将time_t等与时间相关的类型的数据转为Time, 具备时间范围限制(如果超出, 将自动校正), 支持大小比较, 转字符串以及获取年月日等方法 |
| `Key` | 密钥 | 类 | 存储盐和哈希后的密钥, 支持通过密码生成密钥, 设置/验证/修改密钥等方法 |
| `User` | 用户 | 结构体 | 用于存储用户基本信息以及密钥, 提供获取该用户相关的书籍等方法 |
| `UserCmpCondition` | 用于搜索用户时的结构体 | 结构体 | 存储用于判断用户是否符合所选的比较条件, 提供将某些条件设置为无限制的方法, 同时User类提供与该结构体比较的方法 |
| `Book` | 书籍 | 结构体 | 用于存储书籍的基本信息, 提供获取售卖者/预定者/购买者的方法 |
| `BookCmpCondition` | 用于搜索书籍时的结构体 | 结构体 | 存储用于判断书籍是否符合所选的比较条件, 提供将某些条件设置为无限制的方法, 同时Book类提供与该结构体比较的方法 |

### 选择菜单工具 

具体函数声明及定义参见 [menu.hpp](../menu/menu.hpp) 和 [menu.cpp](../menu/menu.cpp)   

#### 菜单

该工具以Menu类(内部存储长度和宽度等基础信息)为基础, 然后提供下面四个类方法  

| 方法名 | 简介 | 包含的元素 |
| --- | --- | --- |
| `showNormal()` | 显示普通菜单 | 返回键+选项 |
| `showBook()` | 显示书籍详情的菜单 | 返回键+选项+书籍详情 |
| `showUser()` | 显示用户详情的菜单 | 返回键+选项+用户详情 |
| `showStatistics()` | 显示统计信息的菜单 | 返回键+选项+统计信息 |
| `showBooks()` | 显示多本书籍信息的菜单 | 返回键+选项+翻页键+多书籍信息 |


这个四个方法是整个程序在窗口中显示内容和对用户行为作出反应的的基础  

#### 块式选项

这是整个选择菜单中灵活性最高的一个, 将多个Selection结构体(带有位置和显示的信息)放入数组中, 然后通过 `showSelections()` 函数就可用达到和上面[菜单](#菜单)一样的效果, 其中注册与登录界面使用的就是这种方式的菜单    


### 文件操作工具

具体函数声明及定义参见 [saveandload.hpp](../process/saveandload/saveandload.hpp) 和 [saveandload.cpp](../process/saveandload/saveandload.cpp)   


提供的功能可用将书籍或者用户信息序列化为Json输出到文件, 或者解析成书籍或者用户信息  


| 函数名称 | 函数类型 | 简介 |
| --- | --- | --- |
| `loadUsersFromFile()` | 重载函数(2个) | 加载并解析json文件中的用户信息, 并返回用户链表 |
| `saveUserToFile()` | 重载函数(2个) | 将用户链表中的用户信息转为Json树, 然后序列化为字符串并存入文件中 |
| `loadBooksFromFile()` | 重载函数(2个) | 加载并解析json文件中的书籍信息, 并返回书籍链表 |
| `saveBooksToFile()` | 重载函数(2个) | 将书籍链表中的书籍信息转为Json树, 然后序列化为字符串并存入文件中 |
